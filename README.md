

🛍️ Mart Express BD - E-Commerce Platform

## 📌 Project Overview
Mart Express BD is a feature-rich e-commerce and reselling web application designed to manage products, categories, shopping cart flows, and seamless customer orders.

## 🛠️ Technologies Used & Why?
* **HTML5, CSS3 & Tailwind CSS:** Used for crafting a vibrant, clean, and modern shopping interface.
* **JavaScript:** Used for managing product filtering, cart calculations, and local storage state.

---

## ✨ Key Features
* ✅ Dynamic Product Catalog & Category Filtering
* ✅ Add to Cart & Real-time Price Calculation
* ✅ Responsive Mobile-First Design
* ✅ Sleek UI with Custom Badges & Banners
